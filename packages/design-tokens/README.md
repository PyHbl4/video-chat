# @video-chat/design-tokens

Набор общих дизайн-токенов (цвета, радиусы, тени) для веб-клиента и админ-панели.

## Использование

```css
@import "@video-chat/design-tokens/tokens.css";
```

Файл `tokens.css` определяет CSS-переменные для светлой и тёмной тем, соответствующие бирюзовому бренду UX-стратегии. Ключевые
переменные:

- `--primary` / `--primary-foreground` — акцент `#10B981` и текст на нём;
- `--radius` — базовый радиус 14px для компонентов и карточек;
- `--shadow-soft` — мягкая тень для всплывающих элементов и карточек;
- `--sidebar-*` — оттенки для shell навигации;
- `--muted`, `--muted-foreground` — цвета для вторичных текстов и состояний.

Токены подключаются до любых компонентных слоёв Tailwind, чтобы `@theme inline` мог использовать значения через `var(--token)`.
