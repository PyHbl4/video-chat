## Назначение

Пакет `@video-chat/design-tokens` содержит файл `tokens.css` с системными переменными бренда. Эти переменные подключаются в
`globals.css` веб-клиента и админки до объявления `@theme inline`, чтобы Tailwind-компоненты работали с единой палитрой.

## Базовые переменные

| Переменная | Значение (light) | Применение |
|------------|------------------|------------|
| `--background` | `#FFFFFF` | Фон страниц и холста приложения |
| `--card` | `#F6F7F8` | Карточки, поповеры, панели |
| `--primary` | `#10B981` | Основные CTA, состояния успеха звонка |
| `--primary-foreground` | `#ECFDF5` | Текст на акцентных кнопках |
| `--muted-foreground` | `#6B7280` | Второстепенный текст и подписи |
| `--radius` | `14px` | Радиус углов для карточек и полей |
| `--shadow-soft` | `0 24px 64px rgba(15,23,42,0.12)` | Мягкая тень карточек |

## Sidebar и графика

- `--sidebar`, `--sidebar-accent`, `--sidebar-border` задают фоновый градиент shell навигации.
- `--chart-1` – `--chart-5` используются для визуализаций метрик в вебе и админке.

## Тёмная тема

Класс `.dark` переопределяет переменные на более глубокие оттенки (`#0A0A0A` фон, `#10B981` сохраняется как акцент) и усиливает
прозрачность теней. Светлые тексты (`--foreground`, `--sidebar-foreground`) настроены для контраста WCAG AA.

## Prefers Reduced Motion

В `tokens.css` предусмотрена адаптация теней при `prefers-reduced-motion: reduce`, чтобы анимации выглядели менее навязчиво. На
этом же хук можно навешивать дополнительные настройки в будущем (например, отключение сложных переходов звонков).

## Как расширять

1. Добавляйте новые токены в `packages/design-tokens/tokens.css` и документируйте их здесь.
2. Для клиентской кастомизации создайте `brand.json` с переопределением ключевых переменных и импортируйте его рядом с токенами.
3. Следите за контрастностью: акцентные элементы должны соответствовать WCAG AA (контраст ≥ 4.5:1 для текста).
