## 1. Концепция

Главное меню состоит из двух зон:

1. **Левый сайдбар** — основная навигация по разделам приложения.  
2. **Верхняя панель (top-bar)** — контекстные инструменты текущей страницы: поиск, фильтры, профиль, переключатель темы.

Обе зоны фиксированы и доступны на всех страницах `/app/*`.

---

## 2. Состав навигации

| Раздел | Путь | Иконка (lucide) | Дополнительно |
|---------|------|-----------------|----------------|
| Друзья | `/app/friends` | Users | бейдж статуса |
| Чаты | `/app/chats` | MessageSquare | — |
| Звонки | `/app/calls` | PhoneCall | бейдж пропущенных |
| Входящие | `/app/inbox` | Inbox | бейдж заявок |
| Настройки | `/app/settings` | Settings | — |

Ниже линии — профиль пользователя (аватар, статус, меню выхода).

## 3. Левый сайдбар

### 3.1. Общие параметры

- **Позиция:** `fixed left-0 top-0 h-screen`  
- **Ширина:**  
  - Collapsed — `72px` (только иконки)  
  - Expanded — `260px` (иконка + текст)  
- **Фон:** `bg-muted/30` (прозрачный, подстраивается под тему)  
- **Разделители:** `border-r` между сайдбаром и контентом  
- **Прокрутка:** отключена, контент сайдбара всегда видим  
- **Переключатель состояния:** кнопка внизу (иконка «<»/«>»)  
- **Состояние:** сохраняется в `localStorage` (`sidebar:collapsed=true/false`)

### 3.2. Элементы меню

Каждый пункт — кнопка с иконкой, подписью и тултипом при свернутом виде.

**Active state:**  

- фон акцентный (`bg-accent/10`)  
- иконка и текст — `text-accent`  
- `aria-current="page"`

**Hover/focus:**  

- фон `bg-muted`  
- тултип `side="right"`

### 3.3. Нижний блок

- Аватар пользователя + статус (онлайн/оффлайн)  
- Кнопка переключения темы (`light ↔ dark ↔ system`)  
- Кнопка выхода (`LogOut` icon)

## 4. Верхняя панель (Top-bar)

### 4.1. Расположение

Фиксируется под хедером приложения:  
`fixed top-0 left-[sidebarWidth] right-0 h-14 border-b bg-background/80 backdrop-blur supports-[backdrop-filter]:bg-background/60`

### 4.2. Контент

| Зона | Элементы |
|------|-----------|
| Левая | Заголовок текущего раздела (`Friends`, `Chats`, …) |
| Центральная | Поиск (`Cmd/Ctrl + K`), фильтры (по статусу, онлайн/оффлайн) |
| Правая | Кнопка «Добавить» (`Plus`), индикатор сети (WebSocket), меню профиля (аватар → dropdown) |

### 4.3. Поведение

- Поиск открывает **командную палитру** (`Cmd/Ctrl + K`)  
- На мобильных: top-bar совмещает заголовок и кнопку открытия сайдбара (`Menu` icon)
- Высота панели — `56–64px`, тень — мягкая `shadow-sm`

---

## 5. Мобильная адаптация

- **Сайдбар скрывается**, заменяется **нижней таб-бар-навигацией**.  
- Таб-бар: `fixed bottom-0 left-0 right-0 h-16 bg-background border-t`
  - Те же иконки (Users, MessageSquare, PhoneCall, Inbox, Settings)
  - Активный — `text-accent`
  - Бейджи отображаются поверх иконок  
- Верхний bar остаётся: заголовок раздела + поиск/добавить.

---

## 6. Конфигурация навигации

Единый объект конфигурации `MAIN_NAV`:

```ts
export type MainRoute = "friends" | "chats" | "calls" | "inbox" | "settings"

export interface NavItem {
  key: MainRoute
  label: string
  href: string
  icon: LucideIcon
  badgeKey?: "inboxCount" | "missedCalls"
}

export const MAIN_NAV: NavItem[] = [
  { key: "friends",  label: "Друзья",   href: "/app/friends",  icon: Icons.Users },
  { key: "chats",    label: "Чаты",     href: "/app/chats",    icon: Icons.MessageSquare },
  { key: "calls",    label: "Звонки",   href: "/app/calls",    icon: Icons.PhoneCall, badgeKey: "missedCalls" },
  { key: "inbox",    label: "Входящие", href: "/app/inbox",    icon: Icons.Inbox,     badgeKey: "inboxCount" },
  { key: "settings", label: "Настройки",href: "/app/settings", icon: Icons.Settings },
]
```

**Store для бейджей:**

```ts
interface UIStore {
  inboxCount: number
  missedCalls: number
  collapsed: boolean
}
```

---

## 8. A11y

- `<nav aria-label="Главное меню">`  
- `aria-current="page"` для активного раздела  
- Все иконки имеют скрытые подписи (`sr-only`)  
- Навигация стрелками (`↑/↓` в сайдбаре, `←/→` в таб-баре)  
- Поддержка `prefers-reduced-motion`

---

## 9. Темы и визуал

- Акцент: бирюзовый `#10B981`  
- Фон сайдбара и top-bar адаптируется к теме  
- Радиусы и отступы согласованы с карточками (`rounded-xl`, `p-3`)  
- Тени — мягкие (`shadow-sm`, `shadow-md` при hover)  
- Анимации появления меню — `transition-all ease-out duration-200`

---

## 10. Definition of Done

- Сайдбар и top-bar доступны на всех страницах `/app/*`.  
- Навигация работает с клавиатуры.  
- Состояние сайдбара сохраняется.  
- Командная палитра (`Cmd/Ctrl + K`) открывается.  
- На мобиле — нижний таб-бар.  
- Акцент и темы корректно меняются.  
- Бейджи обновляются из стора (mock на MVP).

---

**Итог:**  
Вариант 3 объединяет эргономику и чистоту интерфейса. Сайдбар остаётся основным ориентиром пользователя, а верхняя панель — контекстным инструментарием. Макет должен оставаться лёгким, модульным и не мешать фокусу на контенте (Friends/Calls/Chats).
