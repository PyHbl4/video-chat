# Задание для Codex — Реализация UI/UX-каркаса (без логики)

**Контекст:** Репозиторий уже существует. Необходимо реализовать визуальный и навигационный каркас приложения, без бизнес-логики (WebRTC, API, данные).

## Что нужно сделать

### 1. Каркас приложения (App Shell)
- Десктоп: три колонки (сайдбар / список / контент).
- Планшет: сворачиваемый сайдбар, переключение список/контент.
- Мобильная версия: одна колонка + нижняя навигационная панель.
- Добавить глобальные провайдеры темы и уведомлений.

### 2. Маршруты и страницы
- `/app/friends`, `/app/chats`, `/app/calls`, `/app/inbox`, `/app/settings`.
- `/app/search/users` — поиск людей.
- `/call/[roomId]` — экран звонка (только сетка участников и место под тулбар).
- На каждой странице — заголовок, фильтры (если нужны), пустое состояние.

### 3. Компоненты (без логики)
- Навигация: сайдбар, верхняя панель, нижняя таб-бар.
- Списки: карточка друга, чат, история звонков.
- Звонки: сетка участников (1–6), тулбар, модал выбора устройства, баннеры, модал входящего звонка.
- Общие: фильтр (Все/Онлайн/Оффлайн), поле поиска, переключатель темы, компонент пустого состояния.

### 4. Доступность и адаптивность
- Управление клавиатурой и видимая фокусировка.
- Корректные aria-роли и live-заглушки для уведомлений.
- Адаптация под мобильный/планшетный/десктопный лейаут.

### 5. Оформление и темы
- Поддержка светлой, тёмной и системной темы.
- Плейсхолдеры для токенов: цвета, отступы, радиусы, тени.

### 6. Документация
- Короткий раздел в README: как запустить, как переключить тему, как переходить между страницами, как протестировать экран входящего звонка (без сети).

## Критерии готовности
- Навигация работает на всех маршрутах.
- Лейаут корректно перестраивается на трёх брейкпоинтах.
- Экран звонка показывает сетку и тулбар (без действий).
- Входящие отображают пример пустого состояния.
- Управление возможно только с клавиатуры.
