# Self-Hosted Video Chat — UX-бриф
**Дата:** 2025-10-11

Этот документ описывает **пользовательский опыт (UX)** для веб-клиента (настольная и мобильная версия). В нём нет конкретики по коду — только принципы, сценарии и логика интерфейса.

## Цели продукта
- Обеспечить приватное, надёжное общение и звонки для небольших доверенных групп (до 6 человек в одной комнате).
- Концепция self-hosted: пользователь разворачивает всё у себя, данные под его контролем.
- Простота и понятность для конечного пользователя.

## Основные разделы интерфейса
- **Друзья** — управление контактами, статусы, быстрый звонок.
- **Чаты** — текстовое общение (1:1 и малые группы).
- **Звонки** — история звонков и пропущенные.
- **Входящие** — заявки в друзья и пропущенные события.
- **Настройки** — профиль, устройства, качество, приватность, тема оформления.
- **Поиск** — пользователи (на текущем этапе); чаты — позже.

## Навигация
- **Десктоп:** трёхколоночный лейаут — слева сайдбар, посередине список, справа контент.
- **Планшет:** сворачиваемый сайдбар, переключение между списком и контентом.
- **Мобильная версия:** одноколоночный интерфейс с нижней панелью навигации (Друзья, Чаты, Звонки, Входящие, Настройки).

## Основные сценарии
- **Исходящий звонок:** выбрать друга → опциональное окно выбора устройств → подключение → экран звонка.
- **Входящий звонок:** уведомление (toast) + небольшое модальное окно → Принять / Отклонить / Завершить текущий и принять.
- **Вторая линия:** если уже идёт звонок, вверху экрана отображается баннер с действиями.
- **Смена устройств:** во время звонка — выбор микрофона, камеры, динамика с быстрой проверкой.
- **Слабая сеть:** баннер с предложением перейти в аудио-режим; автоматическое снижение качества.

## Экран звонка (до 6 участников)
- Сетка от 1 до 6 тайлов; возможность закрепить участника.
- Панель управления снизу (на десктопе плавающая, на мобиле фиксированная).
- Состояния: подключение, активен, переподключение, завершён.
- Индикаторы: активный спикер, включение/выключение камеры и микрофона, демонстрация экрана.

## Входящие
- Заявки в друзья, пропущенные вызовы и события.
- Основные действия прямо в списке: принять, отклонить, перезвонить, открыть чат.

## Друзья
- Фильтры: Все / Онлайн / Оффлайн.
- Карточка друга: кнопки «Позвонить», «Написать», «Ещё» (заблокировать, профиль).
- Поле поиска пользователей.

## Чаты (MVP)
- Список диалогов + экран сообщений.
- Только текст, история сохраняется.
- В будущем — файлы, реакции, поиск по истории.

## Настройки
- **Профиль:** аватар, имя, ник.
- **Устройства:** микрофон, камера, динамик + тест.
- **Медиа:** пресеты качества (авто/низкое/среднее/высокое), аудио-режим.
- **Приватность:** кто может звонить, блок-лист.
- **Внешний вид:** светлая/тёмная тема, «следовать системе».

## Адаптивность
- Точки перелома: mobile ≤ 767, tablet 768–1023, desktop ≥ 1024.
- На мобильных — крупные основные кнопки, второстепенные в меню.

## Доступность
- Полная работа с клавиатуры: Tab, видимая подсветка, шорткаты (M, V, S, E).
- Live region для статусов звонка, слабой сети, входящих вызовов.
- Диалоги: корректные aria-атрибуты.
- Контраст по WCAG AA, уважение prefers-reduced-motion.

## Обратная связь и пустые состояния
- Для каждого раздела — экран-подсказка при отсутствии данных.
- Эфемерные уведомления через toast; подтверждение перед опасными действиями.

## Визуальный стиль
- Спокойная визуальная палитра, мягкие углы, ненавязчивые тени.
- Светлая и тёмная темы с читаемыми цветами.
- Простая иконография, минимум анимации.

## На будущее
- Поиск по чатам, медиа-сообщения, реакции, уведомления, групповые звонки через SFU.
