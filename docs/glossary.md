## Термины

- *agент* — процесс из `apps/arena-agent`, исполняющий игровые задачи.
- *матчмейкер* — компонент `MatchMaker`, который подбирает ростеры и запускает игры.
- *ростер* — набор дронов/ботов игрока, участвующий в матче.

Документ будет расширяться по мере появления новых определений.
