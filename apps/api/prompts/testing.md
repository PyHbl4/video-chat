# Проверка изменений
- Основной тестовый раннер — `pytest` из каталога `apps/api` (использует асинхронные фикстуры и SQLite in-memory движок).
- Для новых эндпоинтов добавляй проверки в существующие файлы `tests/test_*.py` или создавай новые.
- При работе с аутентификацией проверяй оба сценария: web (cookie + CSRF) и device (Bearer + refresh).
- Если фича зависит от Redis или Socket.IO, добавь monkeypatch/stub, как в тестах дружбы, чтобы изолировать внешние сервисы.
- После изменения моделей прогоняй `alembic revision --autogenerate` и убеждайся, что миграции охватывают новые поля.
- Для ручного прогона можно запустить `uvicorn videochat_api.main:app --reload` и проверить сценарии через HTTP-клиент.
