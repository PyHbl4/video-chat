# Проверка изменений
- Основная команда: `pytest` из каталога `apps/api`. Фикстуры используют in-memory SQLite, `_FakeRedis` и создают приложение через `create_fastapi_app` + `SocketIOFastAPIApp`.
- Покрытие:
  - `tests/test_auth.py` — веб- и device-аутентификация, refresh, логаут.
  - `tests/test_friends.py` — дружба и события Socket.IO.
  - `tests/test_rooms.py` — создание комнат, доступы, join/leave, кэш Redis и Socket.IO уведомления.
  - `tests/test_users.py` — админские списки, поиск, удаление пользователей с дружбой и комнатами.
- При добавлении функциональности обновляйте/создавайте соответствующие тесты. Для Socket.IO событий используйте monkeypatch `sio.emit`, как в текущих сценариях.
- После правок, влияющих на Redis или присутствие, проверяйте, что `_FakeRedis` покрывает новый контракт, либо добавляйте новые методы в фикстуру.
- Перед релизом повторяйте ручной сценарий из README: регистрация, дружба, комната, join/leave, удаление пользователя.
