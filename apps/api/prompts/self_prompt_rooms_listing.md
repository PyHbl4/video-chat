# Self Prompt – список комнат пользователя

## Итоговая реализация
- В модели `Room` появилось поле `target_user_id`, указывающее приглашённого пользователя. Alembic-миграция `20241015_000006` добавляет колонку и индекс.
- `RoomService.list_rooms_for_user` комбинирует активные участия (`room_participants`) и приглашения по `target_user_id`, возвращая комнаты в статусах `waiting`, `active`, `ending`.
- Эндпоинт `GET /rooms/me` возвращает `RoomsListResponse` (список комнат), поэтому инициатор и приглашённый видят одинаковые данные до join.

## Что проверять
- Тесты `tests/test_rooms.py` проверяют сценарии для инициатора, приглашённого и случая без комнат. Убедитесь, что новые поля попадают в схему и сортировка соответствует ожиданиям.
- При изменении статусов обновляйте `RoomService.ACTIVE_STATUSES` и фронтенд, который отображает список.
- Если появятся групповые комнаты, пересмотрите логику `_ensure_user_is_free` и фильтрацию по `target_user_id`.
