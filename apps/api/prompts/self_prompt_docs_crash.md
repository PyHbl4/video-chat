# Self Prompt – падение при открытии Swagger UI

## Итоговая реализация
- Вместо прямого `socketio.ASGIApp` используется собственный адаптер `SocketIOFastAPIApp`. Он пропускает события `lifespan` во внутренний FastAPI, подменяет `scope['app']` только на время обработки HTTP-запроса и направляет пути `/socket.io` в Socket.IO сервер.
- Благодаря этому Swagger (`/docs`) и OpenAPI (`/openapi.json`) работают так же, как в чистом FastAPI-приложении, а uvicorn с `--reload` больше не падает.

## Что проверять
- В `tests/conftest.py` приложение для тестов создаётся через `create_fastapi_app` и `SocketIOFastAPIApp`, поэтому ошибка воспроизводится в CI, если адаптер сломать.
- Регрессионные проверки: `GET /docs` и `GET /openapi.json` должны возвращать 200; можно добавить тесты при изменении адаптера.
- При обновлении Socket.IO или FastAPI убедитесь, что интерфейсы `scope`, `receive`, `send` не поменялись, иначе адаптер потребует корректировок.
