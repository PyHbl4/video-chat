# Self Prompt – REST-присоединение к комнате

## Итоговая реализация
- Эндпоинт `POST /rooms/{room_id}/join` принимает UUID, авторизует пользователя через `get_current_user` и вызывает `RoomService.join_room`.
- Сервис проверяет дружбу, ограничение в два участника и возвращает пару `(room, changed)`. При `changed=True` статус переключается на `active`, участник добавляется в БД, Redis обновляется, а Socket.IO рассылает `room:user_joined` в `video-room:{id}` и комнаты `user:{id}` остальных участников.
- Повторный вызов возвращает `changed=False`, сохраняя идемпотентность.

## Что важно при изменениях
- `RoomService` нормализует Enum-значения, поэтому не ломается при строковых статусах PostgreSQL.
- Тесты в `tests/test_rooms.py` покрывают join: проверяют статус, событие Socket.IO и поведение повторного вызова. При модификации контракта обновите тесты и заглушку `sio.emit`.
- Если меняется payload события, синхронизируйте фронтенд и описание в README/knowledge.
