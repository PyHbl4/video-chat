# Self Prompt – 500 на `/auth/me` после добавления `is_admin`

## Итоговая реализация
- Схема `UserResponse` принимает как `is_admin`, так и alias `isAdmin`, поэтому ORM-объекты `User` валидируются без ошибок. Сериализация использует `by_alias=True`, и фронтенд получает поле `isAdmin`.
- Эндпоинт `GET /auth/me` возвращает pydantic-модель, которую FastAPI автоматически преобразует в JSON; `isAdmin` всегда присутствует и отражает текущий флаг администратора.

## Регрессии, которые стоит держать в голове
- Покрытие есть в `tests/test_auth.py`: проверяется успешный ответ `/auth/me` после логина и отсутствие 500 ошибок.
- При изменении `UserResponse` или модели пользователя обновляйте тесты, чтобы гарантировать, что alias остаётся рабочим.
- Если появятся новые поля у пользователя, повторите подход с alias, чтобы не ломать сериализацию.
