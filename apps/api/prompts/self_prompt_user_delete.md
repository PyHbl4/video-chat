# Self Prompt – удаление пользователя

## Итоговая реализация
- Эндпоинт `DELETE /users/{user_id}` проверяет права: администратор может удалить любого, обычный пользователь — только себя. Неверный ID даёт 400, отсутствие пользователя — 404.
- Перед удалением вызывается `session_manager.revoke_user_sessions`, что отзывает все активные сессии и устройства. Затем запись `User` удаляется; каскады очищают дружбы, сессии, устройства и участие в комнатах.

## Что проверять
- `tests/test_users.py` покрывает сценарии: удаление владельцем, администратором, запрет чужим пользователям, несуществующий ID и очистку дружб/комнат.
- При добавлении новых связанных сущностей убедитесь, что каскады/`passive_deletes` настроены и тесты обновлены.
- Документация (README, knowledge) должна упоминать доступность `DELETE /users/{id}` и последствия удаления (сессии, комнаты, дружба).
