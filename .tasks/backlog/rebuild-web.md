# ownSpace — UI Skeleton Reset

## 🎯 Цель

Полностью сбросить клиентское приложение до минимально работающего прототипа, сохранив структуру навигации и все UI-компоненты.  
Стек: **Next.js 15 + TailwindCSS + shadcn UI**.  
Всё приложение должно запускаться локально командой `pnpm dev` (или `npm run dev`) и иметь корректную маршрутизацию между страницами.

## 🧭 Навигация (Sidebar Layout)

- **ownSpace** (логотип, переход на `/app/friends`)
- 🧑‍🤝‍🧑 Друзья → `/app/friends`
- 💬 Комнаты → `/app/rooms`
- 📥 Входящие → `/app/inbox`
- ⚙️ Настройки → `/app/settings`
- 🪪 Профиль → `/app/profile`
- 🌗 Переключение темы
- 🚪 Выход

**Sidebar** и **Topbar** реализовать как отдельные компоненты (`layout/sidebar.tsx`, `layout/topbar.tsx`).

## 📄 Требования к страницам

### `/app/friends`

- Поиск (`Input`)
- Tabs-фильтры: Все / Онлайн / Оффлайн
- Список друзей (`FriendCard`)
- Пустое состояние при отсутствии друзей
- Кнопки: “Новый чат”, “Запланировать звонок”

### `/app/inbox`

- Список заявок: входящие / исходящие (`Card`)
- Кнопки: “Принять”, “Отклонить”, “Отозвать”

### `/app/rooms`

- Плейсхолдер: “Комнаты скоро появятся”
- Кнопка “Создать комнату” (disabled)

### `/app/settings`

- Настройка VDS-подключения (`Input`, `Button`)
- Тема интерфейса (toggle)
- Поле для API-ключа или адреса сигнального сервера

### `/app/profile`

- `Avatar`, никнейм, email
- Кнопка “Редактировать”

### `/onboarding`

- Три шага:
  1. Приветствие
  2. Подключение VDS
  3. Установка профиля

## ⚙️ Общие требования

- **Tailwind** и **shadcn** подключены и сконфигурированы.
- Навигация реализована через `usePathname` и `next/link`.
- Тема (светлая/тёмная) — через `ThemeProvider`.
- Все базовые UI-компоненты сохраняются в `/components/ui` без изменений.
- В `layout.tsx` реализовать общий каркас с сайдбаром и топбаром.
- Пустые страницы должны содержать минимальную структуру (заголовок, описание, placeholder-контент).
