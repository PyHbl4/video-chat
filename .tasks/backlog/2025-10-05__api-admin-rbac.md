## Контекст

Stage 5 требует ролей user/moderator/admin и эндпоинтов для блокировок, просмотра активных звонков. Сейчас RBAC отсутствует, `User.is_blocked` управляется только вручную.

## Что сделать

- [ ] Добавить роли и таблицу привязки (например, `user_roles` или поле role с ENUM), миграцию.
- [ ] Внедрить middleware/Depends для проверки ролей, расширить `settings` для списка супер-админов.
- [ ] Реализовать эндпоинты админки: список пользователей, блокировка/разблокировка, активные комнаты/звонки.
- [ ] Добавить аудиторские записи (минимум: кто заблокировал, когда) и логирование.
- [ ] Написать тесты RBAC + сценарии блокировки (влияет на login/active sockets).
