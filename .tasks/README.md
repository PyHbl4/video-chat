# Журнал задач .tasks

Этот каталог хранит карточки задач в текстовом виде. Статус задачи определяется подпапкой, в которой лежит файл.

## Статусы
- `backlog/` — идеи и невзятые задачи.
- `in-progress/` — активная работа.
- `review/` — задача на проверке, тестах или ожидании слияния.
- `done/` — завершённые задачи, перенесённые сюда после закрытия.

## Формат файла
- Имя файла: `ГГГГ-ММ-ДД__slug.md`. Дата — когда задача создана или принята в работу; `slug` — короткий идентификатор через дефис.
- В начале файла — YAML-фронтматтер с ключами:
  - `title` — короткое название задачи.
  - `status` — один из `backlog`, `in-progress`, `review`, `done`.
  - `assignee` — ответственный.
  - `priority` — `low` | `medium` | `high` | `critical`.
  - `eta` — ожидаемая дата завершения (`ГГГГ-ММ-ДД`) или `null`.
  - `tags` — список коротких меток.
  - `links` — список внешних ссылок или идентификаторов.
- После фронтматтера — тело с разделами: «Контекст», «Что сделать», «Заметки» (можно добавлять свои блоки).

## Жизненный цикл
1. Создать файл на основе шаблона `_template.md` и разместить в `backlog/`.
2. При начале работы переместить файл в `in-progress/` и обновить поля (`status`, `assignee`, `eta`).
3. Когда задача готова и ожидает проверки, перенести в `review/`.
4. После принятия/слияния — переместить в `done/` и дополнить фактическими результатами.

## Автоматизация
При большом количестве карточек можно завести вспомогательные скрипты для генерации индекса или проверки фронтматтера. Пока что структура поддерживается вручную.
